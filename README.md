# datasci_1_loading
##Hamza Sulemanjee

###Content
This repository contains my HHA 507 Data Science for Healthcare Assignment 1. The project uses Google Colab and pandas to load and review nine healthcare related datasets, including three CSV files, three XLSX files, and three JSON files. Each dataset is loaded into a separate DataFrame, the first 10 rows are displayed, and the main features of each dataset are described in the notebook. The `data` folder contains all nine datasets used for the assignment.
